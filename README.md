# IBM Data Science Capstone Project

## Project Overview
This project focuses on analyzing SpaceX Falcon 9 first-stage landing outcomes and developing machine learning models to predict landing success.

## Objectives
- Collect and explore SpaceX launch data.
- Perform data wrangling and exploratory data analysis.
- Analyze launch data using SQL.
- Create interactive visualizations and maps.
- Develop and evaluate classification models.
- Identify insights from launch data.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- SQL
- Folium
- Plotly Dash
- Scikit-learn
- GitHub

## Project Status
In progress. Notebooks, analysis results, visualizations, and the final report will be added as the project is completed.
